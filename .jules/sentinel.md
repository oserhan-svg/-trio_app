## 2024-05-18 - [Critical Unauthenticated Remote Command Execution via Database Migration Route]
**Vulnerability:** Found a publicly accessible, unauthenticated HTTP GET endpoint (`/internal/migrate`) mapped to a controller function `runInternalMigration` in `server/controllers/dealController.js` and `server/routes/dealRoutes.js`. This function executed a raw child process (`exec`) command running Prisma migrations (`prisma migrate dev --name add_deals_model --skip-generate`).
**Learning:** This route was likely left behind accidentally from a development or testing phase to quickly run DB migrations without having CLI access. This created a high severity command injection or denial of service risk (e.g., dropping databases via tampered migrations) because it bypassed authentication middlewares.
**Prevention:** Database migrations should strictly remain part of the deployment pipeline or run via CLI scripts (`pnpm db:migrate` etc.), never exposed as a web route. Code review must ensure experimental endpoints are removed or disabled before deploying to production.
