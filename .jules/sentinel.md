## 2025-03-08 - Critical Vulnerability: RCE in Internal Migration Route
**Vulnerability:** Command Injection / RCE vulnerability in `server/controllers/dealController.js` via the internal migration route `/api/deals/internal/migrate`. Although it's hardcoded to execute Prisma, it lacks both `authenticateToken` and `authorizeRole('admin')` middleware.
**Learning:** Internal tooling routes added for migrations or temporary fixes can accidentally be left exposed, allowing unauthenticated users to trigger server-side execution.
**Prevention:** The route `/internal/migrate` and its implementation `runInternalMigration` must be removed completely from production builds, or heavily guarded by both `authenticateToken` and `authorizeRole('admin')`. Since memory explicitly tells me that "Internal or testing routes in the Express server (e.g., those executing database migrations via `child_process.exec`) must be completely removed from production builds or strictly protected with both `authenticateToken` and `authorizeRole('admin')` to prevent RCE/Command Injection vulnerabilities," I will enforce the latter if I keep it, or remove it. I will choose to remove it since it's a migration script meant for one-time use.
