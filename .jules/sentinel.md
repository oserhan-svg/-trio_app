## 2024-05-31 - Command Injection Vulnerability in dealRoutes.js
**Vulnerability:** Command injection and unauthorized schema execution in `/internal/migrate` route (`dealController.runInternalMigration`). The endpoint allows execution of arbitrary shell commands in `runInternalMigration` using `child_process.exec` because the route lacks `isAdmin` authorization, even though it executes sensitive DB commands (`prisma migrate`). Furthermore, it exposes standard output and standard error which leaks internal server information.
**Learning:** `dealController.runInternalMigration` uses `exec` to run Prisma migrations, but lacks administrative role checks in `dealRoutes.js`. While the command itself doesn't take raw user input directly, its presence without role checks enables any authenticated user (or unauthenticated depending on route setup) to arbitrarily trigger database schema changes.
**Prevention:** Always restrict routes executing shell commands or database administration tasks with strong RBAC (like `isAdmin`). Always sanitize/remove `stderr` or raw command output in API responses.
