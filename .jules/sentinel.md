## 2024-11-08 - Unauthenticated API Route /internal/migrate\n**Vulnerability:** The unauthenticated API route `/internal/migrate` calls a controller which executes a shell command using `exec`. This is essentially command injection disguised as a feature.\n**Learning:** Debug/internal features that run arbitrary commands should never be present in API routes, especially unauthenticated ones.\n**Prevention:** Avoid unauthenticated administrative routes. The endpoint and its logic have been removed.
