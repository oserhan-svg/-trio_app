## 2024-05-18 - Fix unauthenticated Command Injection in internal API route
**Vulnerability:** A test route `GET /internal/migrate` was discovered in `dealRoutes.js` that was unauthenticated (missing `authenticateToken` middleware) and executed a shell command (`exec` from `child_process`) on the server to run a Prisma database migration.
**Learning:** Development/testing routes utilizing powerful server-side functions like `child_process.exec` are sometimes left in production builds. The lack of authentication meant anyone discovering the route could trigger a server-side action. While the command was hardcoded, leaving `exec` exposed via web endpoints is highly dangerous.
**Prevention:** Never use `child_process.exec` or similar methods in web-accessible endpoints. Ensure that all internal/testing routes are removed before production, or at the very least, strongly authenticated and restricted to admin roles. Use proper application-level mechanisms or secure CI/CD pipelines to manage database migrations instead of executing shell commands from the Express app.
