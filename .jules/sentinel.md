## 2024-05-09 - Remove Unprotected Migration Route
**Vulnerability:** Found an unprotected API route `/internal/migrate` mapped to `dealController.runInternalMigration` which executed a shell command (`child_process.exec`) with database migration logic. This route had no authentication or authorization checks.
**Learning:** Testing or internal routes executing commands must not be deployed to production. If an internal endpoint uses `child_process.exec` without strict input validation and admin-level authentication, it introduces significant Remote Code Execution (RCE) / Command Injection risks.
**Prevention:** Database migrations should be strictly handled via secure CI/CD pipelines, Dockerfile RUN commands, or secure deployment scripts rather than exposed web API routes. Ensure any internal testing endpoints are thoroughly scrubbed before merging to a production codebase, and always employ robust authentication (e.g., `authenticateToken`) and authorization (e.g., `authorizeRole('admin')`) mechanisms on sensitive routes.
