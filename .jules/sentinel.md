## 2024-05-18 - Unauthenticated Command Injection via Database Migration Route
**Vulnerability:** The `/internal/migrate` endpoint in `server/routes/dealRoutes.js` allowed completely unauthenticated remote code execution. It directly called `child_process.exec` in `server/controllers/dealController.js` to run a database migration script.
**Learning:** Development/debug routes that execute system commands are often left in production code accidentally. Because they bypass all middleware (no `authenticateToken` or `authorizeRole` mapped to it), they pose an immediate and critical risk of unauthorized remote command execution.
**Prevention:** Never leave internal test or migration endpoints in the production codebase. Database migrations should always be handled in the deployment pipeline or via secure, authenticated CLI scripts, not exposed through the web server's routing layer. If temporary debugging routes are needed, they must be rigorously authenticated and removed prior to merging.
