## 2024-03-24 - Parallelize Independent Prisma DB Queries inside Promise.all Map Loops
**Learning:** Sequential Prisma queries inside `.map` loops represent a significant N+1-like latency stacking bottleneck, multiplying network roundtrips. Even if the outer loop is parallelized using `Promise.all(collection.map(...))`, sequential await calls *inside* the map callback will still block each individual iteration.
**Action:** When calculating metrics or aggregating multiple independent statistics using Prisma or independent async data service calls in backend controllers, always group them into arrays and use `Promise.all([query1, query2])` inside the `.map` callback to execute them concurrently, achieving maximum concurrency and reducing total response latency to the longest single query time.
