## 2025-02-12 - Concurrent Query Execution
**Learning:** In controller logic that iterates through arrays and executes sequential database queries using `await` within `map` functions, it leads to independent queries being queued. Grouping `await prisma.property.count({...})` and similar requests in a single `Promise.all` inside `.map` greatly improves concurrency, but wrapping that `.map` inside another `Promise.all` executes ALL iterations concurrently, rather than waiting for each element in sequence or suffering N+1 issues.
**Action:** Use `Promise.all([ promise1, promise2 ])` to resolve multiple independent queries concurrently for a specific controller. Always wrap the entire mapping in `Promise.all()` to achieve full parallelization for iterative stats compilation.
