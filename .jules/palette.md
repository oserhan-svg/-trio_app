## 2025-05-15 - Micro-UX and Accessibility Audit
**Learning:** Standardizing core UI components (Button, Input) with built-in accessibility (ARIA) and state feedback (isLoading) simplifies maintenance and ensures a baseline level of UX across the entire application. Specifically, ensuring all button variants have consistent disabled styles prevents "dead" interactions that look active.
**Action:** When modifying shared UI components, audit all variants and usage patterns to ensure consistency. Use Turkish ARIA labels to match the application's primary locale.
