## 2025-06-25 - Accessibility Improvements in AppShell
**Learning:** Icon-only buttons in the main navigation (Menu, Theme, Notifications) lacked proper `aria-label` attributes and explicit `focus-visible` states, which hindered keyboard navigation and screen reader accessibility. Sequential Playwright tabbing (`page.keyboard.press('Tab')`) can sometimes fail to reliably traverse all interactive elements if complex DOM structures intercept focus.
**Action:** Always verify icon-only buttons have descriptive `aria-label` attributes and use Tailwind's `focus-visible:` utility classes (e.g., `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-blue-500`) to ensure clear visual feedback during keyboard navigation. Use direct DOM queries for testing when sequential tabbing is unreliable.
