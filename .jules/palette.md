## 2025-02-27 - AppShell Component Navigation Accessibility
**Learning:** Core navigational components (like AppShell topbar) often use icon-only buttons (Menu, Theme Toggle, Notification) for a clean visual aesthetic, but these fail completely for screen readers if missing `aria-label` and `title` attributes. In this application, these critical navigation pieces were completely inaccessible. When inspecting source files containing Turkish characters, the bash terminal may display them as octal escapes (e.g., `\304\261`), requiring careful string matching and Unicode replacements (e.g., `\u0131`) in React components.
**Action:** When auditing global layout components, explicitly check all icon-only interactive elements for `aria-label` and `title` attributes. Always use React-friendly Unicode escapes when adding localized accessibility labels to ensure proper rendering without literal string issues.
