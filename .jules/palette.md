## 2025-02-20 - Non-ASCII Characters in Git Merge Diffs
**Learning:** When using `replace_with_git_merge_diff` on files containing localized, non-ASCII text (like Turkish 'Hızlı ara...'), the trace output may display these characters as single-escaped octal sequences (e.g., `H\304\261zl\304\261 ara...`). Providing these single-escaped sequences or literal Unicode characters in the `SEARCH` block will cause the patch to fail.
**Action:** When creating a `SEARCH` block that must match octal escape sequences shown in the trace, always double-escape the backslashes (e.g., `H\\304\\261zl\\304\\261 ara...`). For the `REPLACE` block in JSX files, use Unicode escape sequences wrapped in curly braces (e.g., `placeholder={"H\u0131zl\u0131 ara..."}`) to safely inject non-ASCII characters without relying on specific file encoding or risking React rendering raw backslashes.
