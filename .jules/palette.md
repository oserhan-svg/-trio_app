## 2025-05-02 - Add ARIA labels and focus states to Carousel navigation
**Learning:** Carousel navigation buttons using Lucide icons lacked essential `aria-label` properties and explicit `focus-visible` styles for screen reader and keyboard accessibility, which are common issues for icon-only buttons.
**Action:** Applied `aria-label`, `title`, and explicit Tailwind `focus-visible:ring-2 focus-visible:ring-emerald-500` styles to ensure these interactive elements are fully accessible.
