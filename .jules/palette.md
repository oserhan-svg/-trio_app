## 2024-06-11 - Custom Navigation Menus & Keyboard Navigation Focus
**Learning:** In custom React layouts with both a sidebar and a bottom navigation (like AppShell), using visual active classes is insufficient for assistive technologies to identify the current page context. Additionally, interactive icon-only buttons often lack focus-visible styles, making keyboard navigation difficult to track.
**Action:** Conditionally append `aria-current="page"` to custom navigation `<button>` components when they represent the active route. Always use Tailwind's `focus-visible` utilities (e.g., `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-blue-500`) to ensure keyboard users have clear visual feedback without compromising mouse user aesthetics, and provide localized `aria-label`s for icon-only inputs/buttons.
