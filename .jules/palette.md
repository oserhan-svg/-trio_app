## 2025-05-14 - Standardizing Core UI Components for UX & Accessibility
**Learning:** Centralizing accessibility (ARIA) and loading states within core UI components (Button, Input) ensures consistency across the app and reduces manual errors. Using React's `useId` is the most reliable way to link labels and inputs in a large application.
**Action:** Always favor enhancing the shared component library over making one-off local fixes for accessibility or loading feedback.
