## 2025-05-15 - Centralized Loading States and ARIA Accessiblity
**Learning:** Prioritizing centralized loading states within the base `Button` component ensures standardized visual feedback and ARIA accessibility (`aria-busy`, `aria-live`) across the entire application, while reducing boilerplate in form components.
**Action:** Always check if the base UI components can handle common UX patterns (like loading or disabled states) before implementing them manually in specific views.
