## 2024-07-04 - Icon Button Accessibility and Focus States
**Learning:** Icon-only navigation buttons in components like `OpportunityCarousel` must have explicit Turkish `aria-label` attributes for screen readers and visible focus indicators for keyboard navigation. Testing focus states on elements dynamically rendered or conditionally navigated might require simulating tab presses or explicitly routing to a dedicated test path during Playwright automation if standard locators fail to trigger the style.
**Action:** Always include localized `aria-label` or `title` props on icon-only interactive elements and enforce `focus-visible:` utility classes like `focus-visible:outline-none focus-visible:ring-2` to ensure proper accessibility compliance out of the box. Ensure any temporary test routes added to `App.jsx` for verification are reverted before submitting.
