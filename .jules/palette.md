## 2024-05-02 - Ensure AppShell Header Navigation Elements Are Keyboard Accessible
**Learning:** The main global navigation icons in `AppShell` (menu toggle, theme toggle, notifications, and logout) lacked proper descriptive `aria-label`s for screen readers (as they were icon-only), and more critically, they lacked `focus-visible` styles, rendering them entirely invisible to keyboard navigators when tabbed. The search input container also lacked a clear focus outline.
**Action:** Always add semantic `aria-label`s to icon-only buttons (like those using `lucide-react` icons). Additionally, systematically apply Tailwind's `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-offset-2` (and `focus-within` for composite input wrappers) to ensure interactive header elements are fully keyboard navigable.
