## 2024-10-11 - Add ARIA Labels to Navigation Buttons
**Learning:** Icon-only navigation buttons in the primary layout (AppShell) lack accessible names, making them difficult for screen reader users to understand.
**Action:** Always add explicit `aria-label` attributes to icon-only buttons (such as Menu, Notifications, and Theme toggle) in navigation bars, ensuring the text is localized (e.g., Turkish in this application).
